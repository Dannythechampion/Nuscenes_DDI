# DDI 연구 목적 및 타당성 검증 프레임워크

## 1. 한 문장 연구 목적

> 선행 연구, 공식 데이터셋 기준 및 NuScenes 분포 분석을 바탕으로 인지·예측·판단·제어 DDI 지표를 설계·보정한 뒤, 서로 다른 두 개 이상의 자율주행 AI 모델에 동일한 장면을 평가하게 하여 DDI가 실제 오류율과 성능 저하를 일관되게 예측하는지 검증한다.

쉽게 표현하면 다음과 같다.

> 우리가 어려울 것이라고 점수를 매긴 장면에서 실제로 여러 자율주행 AI가 더 자주 틀리는지 확인한다.

DDI는 난이도의 정답이 아니라 AI 성능 저하를 사전에 예측하는 가설적 측정 도구다.

## 2. 교수님 피드백과의 연결

각 기준값은 임의로 설정하지 않고 다음 근거 중 하나 이상을 가져야 한다.

- 논문에서 사용된 기준
- 여러 연구에서 반복 사용된 관행적 기준
- 공식 데이터셋의 난이도 또는 평가 기준
- 센서 성능과 물리적 한계
- 통계적 분석과 수학적 계산
- 실제 주행 환경의 안전·comfort 기준

KITTI와 Waymo 등의 기준은 초기 후보를 정하는 객관적 출처로 사용한다. 다만 센서 구성, 해상도, 객체 분포와 수집 환경이 NuScenes와 다르므로 해당 수치를 그대로 최종 기준으로 사용하지 않는다.

## 3. 타당성의 세 단계

| 단계 | 핵심 질문 | 검증 방법 |
|---|---|---|
| 이론적·내용 타당성 | 왜 이 변수와 수치를 선택했는가? | 논문, 공식 기준, 센서·물리 근거 |
| 통계적 타당성 | NuScenes에서 장면을 실제로 구분하는가? | 분포, 포화율, 민감도, 편향 분석 |
| 준거·예측 타당성 | 어려운 장면에서 AI가 실제로 더 틀리는가? | 오류율, 성능 저하, 여러 모델 비교 |

외부 기준은 임계값의 출발점이고, NuScenes 분포는 적용 가능성을 검사하는 calibration 자료이며, AI 오류는 최종 예측 타당성을 평가하는 준거다.

## 4. 전체 연구 절차

### 1단계: 초기 지표 설계

- PPT에서 제안한 인지·예측·판단·제어 요소를 계산 가능한 수식으로 정의한다.
- KITTI, Waymo, nuPlan, 관련 논문 및 센서 한계에서 초기 기준값 후보를 확보한다.
- 각 변수의 출처, 선정 이유와 예상 효과를 기록한다.

### 2단계: 분포 분석 및 calibration

- NuScenes에서 지표의 분포, 결측, 포화와 쏠림을 확인한다.
- 클래스, 거리, 센서, 날씨와 환경에 따른 편향을 검사한다.
- max 집계 포화, 의도하지 않은 가중치와 중복 변수를 수정한다.
- 이 단계에서는 지표와 임계값을 수정할 수 있지만 모든 변경 근거를 기록한다.

### 3단계: 지표 동결

- 사용할 변수, 수식, 가중치와 임계값을 확정한다.
- 잠정 Easy·Moderate·Hard 구간을 정의한다.
- 사용할 데이터 split, 모델, checkpoint, 오류 지표와 성공 기준을 사전에 고정한다.
- 이후 validation 결과를 보고 같은 기준을 유리하게 다시 조정하지 않는다.

### 4단계: 구성요소별 모델 평가

| DDI 영역 | 모델이 수행할 과제 | 주요 오류 지표 |
|---|---|---|
| 인지 | 객체 검출 및 추적 | FN rate, FP/keyframe, recall, 위치·크기·방향 오차 |
| 예측 | 주변 객체 궤적 예측 | ADE, FDE, miss rate |
| 판단·계획 | 경로 생성 및 행동 선택 | 충돌, 경로 실패, 진행률, 주행 영역·규칙 위반 |
| 제어 | 목표 경로 추종 | 추종 오차, jerk, 급가감속, 차선 이탈 |
| 통합 DDI | 전체 자율주행 stack | 충돌률, task failure, 종합 성능 저하 |

### 5단계: 두 개 이상의 모델에서 반복 검증

한 모델에서만 관계가 나타나면 특정 모델의 약점을 측정한 것일 수 있다. 동일 과제에서 구조가 다른 모델을 최소 두 개 이상 사용한다.

- Camera 인지: FCOS3D, PGD
- LiDAR 인지: PointPillars, CenterPoint
- 예측: 구조가 다른 trajectory prediction 모델 두 개 이상
- 계획: 서로 다른 planner 두 개 이상
- 제어: 서로 다른 controller 또는 policy 두 개 이상

Camera와 LiDAR처럼 입력 modality가 다른 모델은 동일 성능을 직접 비교하지 않는다. `P_camera`와 `P_lidar`를 각각 검증한 뒤 공통적인 난이도 경향을 확인한다.

### 6단계: 단순 baseline과 비교

복합 DDI가 다음 단순 기준보다 오류와 성능 저하를 더 잘 설명하는지 확인한다.

- 객체 수
- 평균 객체 거리
- 교차로 여부
- 곡률
- LiDAR point 수
- 단순 가중합
- 데이터 분위수만 사용한 분류

복합 DDI가 단순 기준보다 추가 설명력이나 예측력을 제공하지 못하면 복잡한 공식을 사용할 근거가 약하다.

### 7단계: 외부 검증

- 다른 모델과 checkpoint
- 다른 센서 구성
- 다른 도시와 환경
- KITTI, Waymo, Argoverse 2, nuPlan 등 외부 데이터셋

에서 동일한 관계가 반복되는지 확인한다. 외부 데이터셋은 전체 DDI의 정답지가 아니라 각 구성요소를 교차검증하는 자료로 사용한다.

## 5. Easy·Moderate·Hard의 의미

세 그룹을 동일한 비율로 만들 필요는 없다. 실제 데이터가 대부분 보통 환경이라면 그룹 비율이 불균형해도 된다.

먼저 연속 DDI 점수에서 다음을 검증한다.

- DDI가 증가할수록 오류율이 증가하는가?
- 관계가 단조적인가?
- 오류가 급격히 증가하는 변곡점이 있는가?

그 후 잠정 구간에서 다음 관계를 확인한다.

\[
Error_{Easy} < Error_{Moderate} < Error_{Hard}
\]

이 관계가 여러 모델에서 반복돼야 Easy·Moderate·Hard 분류의 타당성을 주장할 수 있다. 안정적인 세 단계 경계가 없지만 연속 점수와 오류 사이에 관계가 있다면, DDI를 연속 지표로만 유지하는 결론도 가능하다.

## 6. 순환논증 방지

객체 수를 DDI에 사용하면서 총 오류 개수만 비교하면 객체가 많기 때문에 오류도 많아지는 당연한 관계를 난이도 효과로 오해할 수 있다.

따라서 다음을 사용한다.

- 객체당 FN rate와 recall
- FP/keyframe
- 클래스·거리 조건부 오류율
- 단순 객체 수 baseline
- DDI의 추가 설명력
- calibration과 validation scene 분리

오류가 가장 크게 차이 나는 임계값을 validation 데이터에서 탐색한 뒤 같은 데이터로 타당성을 주장하지 않는다. 수정이 필요하면 새로운 DDI 버전으로 기록하고 별도 데이터에서 다시 검증한다.

## 7. 결과에 따른 주장 범위

| 결과 | 가능한 주장 |
|---|---|
| 한 모델에서만 관계가 나타남 | 특정 모델에 대한 난이도 |
| 같은 과제의 여러 모델에서 반복됨 | 해당 모델군·과제의 난이도 |
| 인지·예측·계획·제어에서 각각 반복됨 | 자율주행 stack 전반의 장면 난이도 증거 |
| 외부 데이터셋에서도 반복됨 | 제한된 범위의 일반화 증거 |

어떤 경우에도 모든 자율주행 시스템에 보편적으로 적용되는 절대 난이도라고 과도하게 주장하지 않는다.

## 8. 현재 진행 위치

현재까지 완료한 작업:

1. 인지 DDI 후보 변수를 NuScenes에서 계산하도록 구현
2. 공식 `v1.0-mini`와 trainval01 shard의 분포·포화·편향 분석
3. LiDAR point의 클래스·거리 의존성 확인
4. 기존 max 집계와 고정 임계값의 문제 확인
5. prediction-GT 오류 매칭 pipeline 구현 및 self-test

현재 확보한 trainval01 shard는 85 scenes, 3,376 keyframes로 전체 trainval의 9.886%다. 이 중 공식 validation scene은 23개다.

아직 완료하지 않은 핵심 작업:

1. 두 개 이상의 실제 인지 모델 prediction 생성
2. DDI와 FN/FP·localization error 관계 검증
3. 잠정 Easy·Moderate·Hard 경계 동결 및 sensitivity analysis
4. 판단·제어 구성요소 검증
5. 전체 DDI와 단순 baseline 비교

따라서 현재 DDI는 타당성이 입증된 최종 난이도 기준이 아니라, 분포와 편향을 점검한 잠정 지표다.

## 9. 최종 발표용 표현

> 본 연구의 목적은 선행 연구와 실제 데이터 분포를 기반으로 자율주행 장면의 인지·예측·판단·제어 난이도 지표를 설계하고, 서로 다른 두 개 이상의 자율주행 AI 모델을 통해 DDI가 실제 오류율과 성능 저하를 일관되게 예측하는지 검증하는 것이다. 이를 통해 DDI 기반 Easy·Moderate·Hard 분류의 객관성, 반복 가능성 및 모델 간 일반화 가능성을 평가한다.
